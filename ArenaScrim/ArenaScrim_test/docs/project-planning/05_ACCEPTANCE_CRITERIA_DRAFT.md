# 05 — Acceptance Criteria (ฉบับร่าง)

> **สถานะเอกสาร:** ร่าง · เกณฑ์ที่ไม่ได้ติดป้ายอิงจากพฤติกรรมที่**โค้ดปัจจุบันตั้งใจให้เป็น** (มีหลักฐานในโค้ด) แต่**ยังไม่ได้ทดสอบว่าผ่าน** เว้นแต่จะระบุไว้
> เกณฑ์ที่ขึ้นกับการตัดสินใจของเจ้าของโครงการติดป้าย **`TBD — รอการยืนยัน`**
> รูปแบบ: **AC-ID · เงื่อนไข → ผลที่ต้องได้ · (หลักฐานในโค้ด) · สถานะการทดสอบ**

## สถานะการทดสอบที่ใช้

- `PASS (หลักฐาน)` — มีผลทดสอบจริงแล้ว
- `NOT RUN` — ยังไม่ทดสอบ
- `TBD` — รอการยืนยันว่าจะใช้เป็นเกณฑ์หรือไม่
