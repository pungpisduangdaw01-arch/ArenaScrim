# 02 — Gap Analysis

> **สถานะเอกสาร:** ร่าง · ไม่ใช่ข้อกำหนด
> **เป้าหมายที่เจ้าของโครงการยืนยัน:** "ระบบรวมทุกฟังก์ชันที่จำเป็นต่อการดำเนินงานทีม RoV"

## 1. แปลงเป้าหมายเป็นสิ่งที่ตรวจสอบได้ (PROPOSAL)

เป้าหมาย "ทุกฟังก์ชันที่จำเป็น" ยังวัดไม่ได้ เพราะไม่มีนิยามว่า "การดำเนินงานทีม" ครอบคลุมอะไรบ้าง และใครเป็นผู้ใช้ เอกสารนี้จึงเสนอ**กรอบชั่วคราว**โดยอิงจากวัตถุประสงค์ 6 ข้อในบทความวิจัย (หัวข้อ "การศึกษาปัญหาและรวบรวมความต้องการ") ซึ่งเป็นเอกสารเดียวในโปรเจกต์ที่ระบุความต้องการไว้

| รหัส | ความต้องการตามบทความ (R) | ตัวชี้วัดที่ตรวจได้ (เสนอ) |
|---|---|---|
| R1 | จัดการข้อมูลทีมและรายชื่อสมาชิกตามตำแหน่ง | หัวหน้าทำ CRUD ทีมและสมาชิกได้ และข้อมูลแยกตามทีม |
| R2 | บันทึกผลการซ้อมแต่ละเกม (คู่แข่ง วันเวลา Bo ผล เวลา objectives ฮีโร่ฝั่งตรงข้าม) | ทุกฟิลด์บันทึกและแก้ไขได้ และค่าที่บันทึกตรงกับที่กรอก |
| R3 | บันทึกสถิติผู้เล่นรายบุคคล | K/D/A, MVP, gold, damage บันทึกได้ต่อผู้เล่นต่อเกม |
| R4 | ค้นหาและวิเคราะห์ข้อมูลย้อนหลัง | ค้นหา/กรองได้ และมีสถิติรายทีม/รายบุคคล |
| R5 | เปรียบเทียบผลงานตามช่วงเวลา | เลือก 2 ช่วงแล้วเทียบตัวชี้วัดได้ |
| R6 | ประกาศหาทีมคู่ซ้อม | โพสต์ ดู ปิด และลบประกาศได้ |

ถ้าเจ้าของโครงการต้องการขอบเขตที่กว้างกว่า R1–R6 ต้องระบุเพิ่ม (ดู Q-01)

## 5. ความสามารถเพิ่มเติมที่อาจมีประโยชน์ แต่ยังไม่มีหลักฐานว่าจำเป็น

| อ่านสถิติจากภาพหน้าจอด้วย OCR | บทความ (งานในอนาคต) | ไม่มีหลักฐานว่าจำเป็นในรอบนี้ |
