# ArenaScrim

เว็บแอปพลิเคชันบริหารจัดการทีมและวิเคราะห์สถิติการซ้อม (Scrim) สำหรับเกม RoV

**ฟีเจอร์หลัก**
- จัดการทีมและรายชื่อสมาชิกตามตำแหน่ง
- บันทึก แก้ไข และลบผลการซ้อม พร้อมสถิติรายบุคคล การควบคุมเป้าหมาย และฮีโร่ฝั่งตรงข้าม
- ประวัติการซ้อม พร้อมค้นหาและกรอง
- สถิติรายบุคคล รายทีม และเปรียบเทียบรายสัปดาห์/รายเดือน
- รายงานผลการแข่งเป็นไฟล์ PDF (dompdf + ฟอนต์ Sarabun)
- วิเคราะห์คู่แข่ง: ผลเจอกันต่อคู่แข่ง และฮีโร่ฝั่งตรงข้ามที่เจอบ่อย
- เปลี่ยนรหัสผ่านเอง และ admin ตั้งรหัสชั่วคราวให้คนที่ลืมรหัสได้
- ตลาดประกาศหาทีมซ้อม
- ส่วนผู้ดูแลระบบ: จัดการสมาชิก ทีม (พร้อมหน้าดูรายละเอียดทีมแบบอ่านอย่างเดียว) ประกาศ และฮีโร่

## เทคโนโลยี

| ส่วน | เครื่องมือ |
|---|---|
| ภาษา | PHP 8.2 (ไม่ใช้ framework), HTML, CSS, JavaScript |
| ฐานข้อมูล | MariaDB 10.4 (MySQL) ผ่าน PDO |
| เว็บเซิร์ฟเวอร์ | Apache (XAMPP 8.2.4) |
| ไลบรารีฝั่งหน้าเว็บ | Chart.js และ Font Awesome (โหลดจาก CDN จึงต้องต่ออินเทอร์เน็ต) |
| PDF | dompdf (ติดตั้งแล้วใน `vendor/`) + ฟอนต์ Sarabun (OFL) ใน `assets/fonts/` |

## การติดตั้ง

1. ติดตั้ง [XAMPP](https://www.apachefriends.org/) แล้วเปิด **Apache** และ **MySQL**
2. คัดลอกโฟลเดอร์โปรเจกต์ไปไว้ใน `htdocs` เช่น `htdocs/ArenaScrim/ArenaScrim`
3. สร้างฐานข้อมูล โดยเปิด phpMyAdmin (`http://localhost/phpmyadmin`) แล้วไปที่ **Import** และเลือกไฟล์ `database/arenascrim_db.sql`
   ไฟล์นี้จะสร้างฐานข้อมูล `arenascrim_db` ตารางทั้ง 7 ตาราง และฮีโร่ 92 ตัวให้เอง
4. ตั้งค่าการเชื่อมต่อใน `config/db.php` (ถ้าใช้ XAMPP ค่าเริ่มต้นคือ `root` และรหัสผ่านว่าง)
5. เปิด `http://localhost/ArenaScrim/ArenaScrim/` (ระบบคำนวณ URL จากตำแหน่งโฟลเดอร์เอง จึงย้ายไปไว้ที่อื่นได้)

> `database/migration_member_info.sql` ใช้**เฉพาะกับฐานข้อมูลรุ่นเก่า**ที่ยังไม่มีคอลัมน์ข้อมูลส่วนตัวใน `team_members` เท่านั้น
> ถ้าติดตั้งใหม่จาก `arenascrim_db.sql` **ไม่ต้องรัน** ไฟล์นี้ เพราะจะเกิด error "Duplicate column"

### สร้างบัญชีผู้ดูแลระบบ

1. สมัครสมาชิกผ่านหน้าเว็บตามปกติ
2. รันคำสั่ง SQL ด้านล่างใน phpMyAdmin โดยเปลี่ยน `your_username` เป็นชื่อผู้ใช้ของคุณ
   ```sql
   UPDATE users SET role = 'admin' WHERE username = 'your_username';
   ```
3. ออกจากระบบแล้วเข้าสู่ระบบใหม่ ระบบจะพาไปที่หน้า Admin

หลังจากนี้ admin คนอื่นสามารถตั้งหรือลดสิทธิ์ได้จากเมนู **จัดการสมาชิก** และการเปลี่ยนสิทธิ์จะมีผลทันที

## วิธีใช้งานโดยย่อ

1. สมัครสมาชิก แล้วสร้างทีมที่เมนู **จัดการทีม** (1 บัญชีสร้างได้ 1 ทีม และจะเป็นโค้ชของทีมนั้น)
2. เพิ่มสมาชิกในทีม พร้อมระบุชื่อในเกมและตำแหน่ง
3. **บันทึกผลการซ้อม** ถ้ากรอก Gold และดาเมจเป็นตัวเลขจริง ระบบจะคำนวณค่าร้อยละให้เอง ผู้เล่นที่ลงเล่นต้องกรอก Gold, MVP, ดาเมจที่ทำ และดาเมจที่รับมากกว่า 0 (K/D/A เป็น 0 ได้) ส่วนผู้เล่นที่ไม่ได้ลงเล่นให้เว้นช่องฮีโร่ไว้
4. ดูผลได้ที่ **ประวัติการซ้อม**, **โปรไฟล์ & สถิติ** และ **สถิติรายสัปดาห์/เดือน**
5. ลงประกาศหาทีมซ้อมได้ที่ **หาทีมซ้อม (Scrim)** ประกาศที่เลยเวลาแล้วจะเปลี่ยนสถานะเป็นหมดเวลาเอง

## โครงสร้างโฟลเดอร์

```
├── index.php, login.php, register.php, logout.php
├── config/
│   ├── db.php           การเชื่อมต่อฐานข้อมูล (PDO)
│   └── functions.php    ฟังก์ชันกลาง: ตรวจสิทธิ์, CSRF, escape, ค่าคงที่ (ตำแหน่ง/แรงก์)
├── includes/            header.php / footer.php ที่ทุกหน้าใช้ร่วมกัน
├── user/                หน้าของผู้ใช้ (ทีม, ผลการซ้อม, สถิติ)
├── scrim/               ตลาดหาทีมซ้อม
├── admin/               หน้าผู้ดูแลระบบ
├── actions/             ไฟล์ประมวลผลฟอร์ม (บันทึก/แก้ไข/ลบ) แล้ว redirect กลับ
├── assets/              CSS, JavaScript, รูปภาพ
├── database/            ไฟล์ SQL (ป้องกันไม่ให้เปิดผ่านเว็บ)
└── docs/                เอกสารประกอบโครงงาน
```

## ความปลอดภัย

- ทุกคำสั่ง SQL ใช้ **Prepared Statement** (PDO) เพื่อป้องกัน SQL Injection
- รหัสผ่านเก็บด้วย `password_hash()` และเปลี่ยน Session ID ทุกครั้งที่เข้าสู่ระบบ
- ทุกข้อความที่แสดงผล escape ด้วย `e()` (`htmlspecialchars`) เพื่อป้องกัน XSS
- ทุกการบันทึก แก้ไข และลบที่ผู้ใช้สั่ง ต้องเป็น **POST ที่มี CSRF token** (`csrf_field()` / `verify_csrf()`) ข้อยกเว้นคือ logout (GET) และการเปลี่ยนสถานะประกาศที่เลยเวลาเป็น "หมดเวลา" ซึ่งทำอัตโนมัติเมื่อเปิดหน้ารายการประกาศ
- ถ้าฐานข้อมูลมีปัญหา ผู้ใช้จะเห็นเฉพาะข้อความทั่วไป ส่วนรายละเอียดจะถูกบันทึกลง error log ของ PHP
- ทุกหน้าตรวจสิทธิ์จากฐานข้อมูล และตรวจความเป็นเจ้าของข้อมูลทุกครั้ง ผู้ใช้จึงแก้ไขหรือดูข้อมูลของทีมอื่นไม่ได้
- `.htaccess` ปิดการแสดงรายชื่อไฟล์ ตั้งค่า cookie เป็น `HttpOnly` / `SameSite=Lax` และเพิ่ม security header

> ค่า `root` และรหัสผ่านว่างใน `config/db.php` เป็นค่าเริ่มต้นของ XAMPP สำหรับเครื่องที่ใช้พัฒนาเท่านั้น
> ถ้าจะนำขึ้นเซิร์ฟเวอร์จริง ต้องสร้างผู้ใช้ฐานข้อมูลแยกและตั้งรหัสผ่าน

## ข้อจำกัดที่ทราบ

- ผู้เล่นในทีมเป็นรายชื่อที่โค้ชจัดการ ไม่มีบัญชีเข้าสู่ระบบของตัวเอง (ออกแบบให้โค้ชเป็นผู้ใช้เท่านั้น)
- ต้องกรอกสถิติเอง เพราะเกมไม่มีช่องทางให้ดึงข้อมูลอัตโนมัติ
- ยังไม่จำกัดจำนวนครั้งที่เข้าสู่ระบบผิด
